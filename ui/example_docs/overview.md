# AI Learning Curriculum Overview

This repository is a set of nine runnable Python lessons teaching how
production RAG, embeddings, agent memory, and multi-agent systems work.
Each lesson lives in its own numbered folder (01 through 09) and pairs
a `main.py` script with a `README.md` explaining the real-world
scenario and concept it teaches.

The curriculum progresses from simple keyword search (module 01)
through semantic search (module 02), short-term and long-term agent
memory (modules 03-04), a full production RAG pipeline with hybrid
search and evaluation guardrails (modules 05-06), tool-calling agents
(module 07), and multi-agent communication and shared knowledge
(modules 08-09).
